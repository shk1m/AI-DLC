## Persona 1: 김영희 (학교 급식 영양사)

| 항목 | 내용 |
|------|------|
| **이름** | 김영희 |
| **역할** | 학교 급식 영양사 |
| **경력** | 8년차 |
| **근무지** | 서울시 소재 중학교 (1,200식/일) |
| **IT 친숙도** | 낮음 - 엑셀과 급식관리 프로그램 사용 수준 |
| **핵심 목표** | 예산 내에서 영양 균형 잡힌 메뉴 계획, 식자재 원가 절감 |
| **Pain Point** | 식자재 가격 급등 시 대체 식재료 찾기 어려움, 수작업 원가 계산 |
| **기대 가치** | 클릭 몇 번으로 시세 확인 + AI가 대체 레시피 추천 |

### 주요 워크플로우
1. 주간 메뉴 계획 수립
2. 식자재 시세 확인 및 주문
3. 가격 급등 시 대체 식재료 탐색
4. 식수별 원가 계산 및 예산 조정

| **경력** | 12년차 |

1. 일별 도소매 시세 모니터링
2. 가격 이상치 발생 시 원인 분석 (뉴스 확인)
3. 전략 상품 기획을 위한 시세 트렌드 분석
4. 공급업체에 제안할 매입가 산정

3. 가격 급등 시 대체 식자재 검토
4. 시즌별 구매 전략 수립

## 페르소나 공통 특성

| 특성 | 설명 |
|------|------|
| **IT 친숙도** | 모두 낮음 → 직관적이고 단순한 UX 필수 |
| **의사결정 기반** | 데이터 + 경험 → AI가 데이터를 정리해서 제시하면 경험으로 판단 |
| **시간 압박** | 모두 바쁜 현장 실무자 → 빠른 인사이트 제공 필요 |
| **신뢰 기준** | 출처가 명확한 데이터만 신뢰 → AI 응답에 출처 필수 |

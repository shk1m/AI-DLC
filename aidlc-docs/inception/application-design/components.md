# 컴포넌트 정의 (Components)

---

## 1. 프론트엔드 컴포넌트 (Next.js 14 + React + TypeScript)

### FE-01: DashboardLayout
- **목적**: Bento-box 레이아웃 기반 메인 대시보드 프레임
- **책임**: 전체 페이지 레이아웃, 네비게이션, 카테고리 탭 관리
- **인터페이스**: 탭 전환 이벤트, 필터 상태 관리

### FE-02: PriceChart
- **목적**: 시세 추이 라인 차트 + Spike 뉴스 매핑
- **책임**: Recharts 기반 차트 렌더링, CustomTooltip, Spike 마커 표시
- **인터페이스**: 품목 ID, 기간 입력 → 차트 데이터 렌더링

### FE-03: CategoryFilter
- **목적**: 식자재 분류 체계 필터링 UI
- **책임**: 카테고리 탭(농산물/수산물/축산물/가공식품), 검색, 정렬
- **인터페이스**: 필터 조건 → 필터링된 품목 목록

### FE-04: PriceTable
- **목적**: 도매가/소매가/Gap 분석 테이블
- **책임**: 품목별 가격 데이터 표시, 정렬, Gap 계산 표시
- **인터페이스**: 품목 목록 데이터 → 테이블 렌더링

### FE-05: CostSimulator
- **목적**: 식수별 비용 시뮬레이션 UI
- **책임**: 식수 입력, 레시피 선택, 원가 계산 결과 표시
- **인터페이스**: 식수/레시피 입력 → 시뮬레이션 결과

### FE-06: ChatBot
- **목적**: 플로팅 AI 챗봇 인터페이스
- **책임**: 채팅 UI, WebSocket 연결, 타이핑 애니메이션, 메시지 렌더링
- **인터페이스**: 사용자 메시지 → AI 응답 스트리밍

### FE-07: SubstituteRecommender
- **목적**: 대체 식자재 추천 결과 표시
- **책임**: 대체 식자재 목록, 가격 비교, 절감률 표시
- **인터페이스**: 원래 식자재 → 대체 추천 목록

## 2. 백엔드 컴포넌트 (FastAPI + LangChain)

### BE-01: PriceService
- **목적**: 시세 데이터 조회 및 분석
- **책임**: KAMIS/공공데이터 API 호출, 시세 캐싱, Spike 감지
- **인터페이스**: 품목/기간 → 시세 데이터 + Spike 이벤트

### BE-02: ChatService
- **목적**: AI 챗봇 대화 처리
- **책임**: LangChain Agent 실행, WebSocket 스트리밍, 대화 이력 관리
- **인터페이스**: 사용자 메시지 → AI 응답 (스트리밍)

### BE-03: RecipeService
- **목적**: 메뉴/레시피 제안 및 원가 시뮬레이션
- **책임**: AI 기반 레시피 생성, 식수별 원가 계산, 영양 정보 조합
- **인터페이스**: 조건(식수, 예산, 제약) → 레시피 + 원가

### BE-04: SubstituteService
- **목적**: 대체 식자재 추천
- **책임**: Neptune 온톨로지 쿼리, 가격 비교, 절감률 계산
- **인터페이스**: 식자재 ID → 대체 식자재 목록 + 절감 정보

### BE-05: NewsService
- **목적**: 뉴스 수집 및 시세 이벤트 매핑
- **책임**: 네이버 API 호출, 크롤링, 키워드 분류, 시간 매핑
- **인터페이스**: 품목/기간 → 관련 뉴스 목록

### BE-06: OntologyService
- **목적**: 식자재 지식 그래프 관리
- **책임**: Neptune 쿼리, 관계 탐색, 분류 체계 제공
- **인터페이스**: 식자재 → 관계(대체가능, 같은분류, 영양유사)

### BE-07: LangChainAgent
- **목적**: AI Agent 오케스트레이션
- **책임**: 질문 분석, 도구 선택(시세조회/레시피추천/대체식자재/뉴스검색), 응답 생성
- **인터페이스**: 자연어 질문 → 구조화된 응답 (출처 포함)

## 3. 데이터 레이어 컴포넌트

### DL-01: PostgreSQL (RDS)
- **목적**: 관계형 데이터 저장
- **책임**: 시세 이벤트, 뉴스 메타데이터, 식자재 마스터, 사용자 데이터
- **ORM**: SQLAlchemy

### DL-02: Amazon Neptune
- **목적**: 식자재 온톨로지/지식 그래프
- **책임**: 식자재 노드, 관계(대체가능, 영양유사 등), 그래프 쿼리
- **쿼리**: Gremlin / openCypher

### DL-03: Amazon Bedrock Knowledge Bases
- **목적**: RAG 벡터 검색
- **책임**: 뉴스 문서 임베딩, 시세 리포트 임베딩, 유사도 검색
- **소스**: S3 버킷의 문서

### DL-04: S3
- **목적**: 문서/데이터 저장소
- **책임**: RAG 소스 문서, 크롤링 원본, 레시피 데이터 저장

## 4. 외부 연동 컴포넌트

### EXT-01: KAMIS API Adapter
- **목적**: 농산물유통정보 API 연동
- **책임**: API 호출, 응답 파싱, 에러 핸들링, 캐싱

### EXT-02: PublicData API Adapter
- **목적**: 공공데이터포털 API 연동 (수산물, 축산물, 가공식품 등)
- **책임**: 다중 API 호출, 통합 응답 포맷

### EXT-03: Naver API Adapter
- **목적**: 네이버 검색 API + 데이터랩 연동
- **책임**: 뉴스 검색, 검색어 트렌드 조회

### EXT-04: NewsCrawler
- **목적**: 정부 보도자료 크롤링
- **책임**: 농림축산식품부/해양수산부 보도자료 수집, 파싱
